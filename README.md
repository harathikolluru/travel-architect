# Travel Architect

An AI travel-planning agent that turns a few trip details into a **plan that survives reality** — a geography-aware, weather-aware, day-by-day itinerary with real, open, bookable restaurants and a backup in every slot.

> Learning / portfolio project — optimized for buildability and demo impact.

## The wedge

Generic AI tools produce a plausible itinerary that breaks on the ground: closed restaurants, days that zigzag across the city, no rain plan, invented addresses. Travel Architect's differentiator is **visible, grounded intelligence**:

- **Geographically efficient** — days clustered so you don't cross the city twice
- **Weather-aware** — each day adapts to the forecast, with indoor alternatives
- **Real, open, relevant places** — pulled from live APIs, never the model's memory
- **Resilient** — a backup in every activity/meal slot
- **Explained** — every item shows its reasoning
